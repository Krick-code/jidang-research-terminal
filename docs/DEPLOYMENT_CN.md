# 中国大陆部署说明

## 当前状态

当前完成的是本地 MVP 和 Cloudflare 兼容预览结构，不是中国大陆正式上线。用户尚未购买域名和服务器，也尚未完成 ICP 备案。

## 正式部署前置条件

1. 购买中国大陆地域云服务器。
2. 购买并实名认证域名。
3. 在服务器所属云厂商提交 ICP 备案。
4. 配置 HTTPS。
5. 把 D1 数据访问适配为服务器 SQLite 或 PostgreSQL；禁止直接把演示数据当生产数据。
6. 在服务器环境变量中配置 Tushare、DeepSeek 与任务密钥。
7. 配置数据库每日备份，并实际完成一次恢复演练。

## 定时器

国内服务器建议用 systemd timer 或云厂商定时触发器调用内部任务接口：

- `0 20 * * *`：判断第二天是否交易日，必要时生成前夜报告；
- `30 8 * * 1-5`：盘前风险补充；
- `0 20 * * 6`：周度复盘。

所有服务器和容器统一使用 `Asia/Shanghai`，并在上线后核对一次真实触发时间。配置存在不等于任务真实执行。

## 预算边界

每月 30 元只适合低配、低并发、活动价或年付折算方案。正式购买前必须检查云厂商官方价格、续费价格、带宽和备案条件。域名、短信、备份和 DeepSeek API 不应混入这 30 元服务器预算。

### 当前部署阻塞

本地 MVP 使用 Cloudflare D1 兼容运行时以完成快速验证，不能直接声称已适配普通国内 Linux 主机。正式国内部署前还必须完成数据库适配层（服务器 SQLite 或 PostgreSQL）、Docker 镜像、独立调度进程、备份恢复脚本和日志轮转。没有服务器、域名、备案与真实密钥时，不进行虚假上线。

## 上线验收

- 域名在中国大陆网络可访问；
- HTTPS 证书有效；
- 5 个账号互相不能读取私人数据；
- 20:00、08:30 和周六任务各产生一次真实日志；
- 服务重启后报告与账本仍存在；
- 数据源失败时明确降级；
- DeepSeek Key 不出现在客户端、日志和构建产物中；
- 完成数据库备份与恢复演练。
