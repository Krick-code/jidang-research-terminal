## 本地运行

1. 复制 `.env.example` 为 `.env.local`，密钥只在本机填写。
2. 生成迁移：`npm run db:generate`
3. 应用本地数据库迁移：`npx wrangler d1 migrations apply site-creator-d1 --local`
4. 当前本地 D1 绑定通过 Wrangler 开发环境提供，执行：`npm run dev`。
5. `npm run start` 只用于生产构建预览，当前不能替代本地 D1 开发环境。
6. 打开：`http://127.0.0.1:3000`

## 本地定时运行

当前采用Windows当前用户的“启动”目录运行最低权限本地调度器，不使用管理员级任务计划程序。登录Windows后，调度器会隐藏启动并维持本地服务：

- 每天 20:00：`{"task":"daily-evening"}`
- 交易日 08:30：`{"task":"preopen"}`
- 每周六 20:00：`{"task":"weekly-review"}`

任务代码具备幂等键和报告锁定。2026-08-09已手动触发前夜任务并成功写入2026-08-10报告；由于当前自选池为空，个人报告按规则标记为部分完成。首次真实20:00准点运行仍必须以 `.local-runtime/task-events.jsonl` 和报告记录为准。电脑关机、休眠或退出当前Windows账户时，本地调度不会运行。

## 数据与 AI

- 免费公开行情：研究台按代码或名称查询股票、ETF 和公募基金；无需用户密钥，60 秒缓存，接口无稳定性承诺，必须交叉核验。
- 历史指标：股票与 ETF 使用前复权收盘价，基金使用累计净值；由程序计算 5/20/60 日收益、20 日年化波动率、60 日最大回撤、20 日区间、均线和 ATR14，不由语言模型补造。
- 历史覆盖：当前最多 120 个披露日，约半年。不能用它证明一年收益稳定性，更不能代表完整牛熊周期。
- 股票基本面：展示最近财务摘要和公告原文镜像入口。财务摘要属于第三方结构化资料；中报等金额通常为年初至报告期末累计值，形成结论前必须回看公司正式定期报告。
- 基金基本面：展示管理人、管理费/托管费、业绩比较基准和最近披露的前十大持仓。季度持仓不是当前持仓，前十大合计不等于股票总仓位；未稳定取得的经理任职期限不展示也不猜测。
- 新闻与政策：媒体新闻先按“标题直接命中/正文提及”筛选，再标注“公告主题支持/多家媒体相似报道/单一媒体线索”；公告主题匹配只确认共享主题，不证明新闻中的数字和因果。政策只展示证监会官网列表与原文入口，关键词相关不等于存在价格因果关系。
- 估值：股票使用接口明确命名的 PE_TTM、PB_MRQ、PS_TTM 字段，展示最近最多750个交易日的正数有效样本分位，并按同一交易日、同一板块比较同行中位数；非正PE不参与统计。基金和ETF按最近披露的前十大持仓计算加权调和平均穿透估值并显示有效覆盖率。历史分位和同行分位都不是“低估”“高估”或目标价结论。
- `TUSHARE_TOKEN`：保留为可选付费增强项；当前免费查询不依赖它。
- 交易日历：2026 年休市安排来自上交所公告；其他年度在正式更新前只按工作日推断并标为部分可信。
- `DEEPSEEK_API_KEY`：每份报告最多调用一次 `deepseek-v4-flash`，只整理最多30条带编号、链接和日期的结构化证据；所有数值计算、评分、候选资格和配置比例都来自程序，模型不得补造或修改。
- 每用户默认每天 10 次主动分析；月度 50 元是应用预算目标，不等于服务商账单硬上限。

## 安全边界

- 密码采用 PBKDF2-SHA256（210,000 次）加盐哈希。
- Session 使用 HttpOnly、SameSite=Strict Cookie；HTTPS 生产环境额外启用 Secure，本地 HTTP 调试不启用 Secure。
- 私人数据按 `user_id` 隔离，权限必须在服务端检查。
- 普通管理页面不能查看其他用户的持仓，但服务器控制者仍可能在运维层访问数据库。
- 不连接券商，不自动下单，不提供杠杆。
